# 暂存“现阶段无法理解”的概念

Teach 默认先正常讲解。普通的“没听懂”“再举个例子”会继续触发澄清，不会自动降低知识深度或暂停概念。

只有用户明确决定以后再学时，才调用：

```text
/skill:defer-concept <概念>
```

系统会保存概念、来源 Quest、当前节点、引入原因、已经讲过的内容、已有实例、卡点和返回位置，并判断该来源是阻塞依赖还是辅助知识。

## 阻塞依赖

拿掉该概念后，当前节点无法达到原完成标准。该节点暂停评估和 Distill；可以先学习其他独立节点。以后完成暂存概念的正式 Learning Quest 后，再返回原节点重新连接两者并正常评估。

## 辅助知识

拿掉该概念后，当前节点仍能达到原完成标准。原节点继续，评估排除该概念；暂存项独立保留，等待以后主动恢复。

同一个概念在不同问题中角色可能不同。例如“电压跟随器”在“设计缓冲级”中可能是阻塞依赖，在“用输出电阻解释负载压降”中可能只是辅助知识。

## 管理命令

```text
/skill:defer-concept list
/skill:defer-concept show DC-001
/skill:defer-concept resume DC-001
/skill:defer-concept cancel DC-001
```

暂存不是掌握证据，不生成 Concept Note、Topic Map 或复习任务。恢复时会创建或继续一个正式 Learning Quest，完成后再处理与原问题的返回关系。
