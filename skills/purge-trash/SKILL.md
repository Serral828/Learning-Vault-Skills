# Purge Trash

永久清空 Vault 根目录直属的 `.trash/`。这是一个不可恢复的独立操作；用户明确调用本 Skill 或明确命令“清空 `.trash`”本身就是授权，不再要求二次确认。

## 执行前验证

在删除前完成全部检查：

1. 解析当前 Vault 根目录，不接受用户提供的替代删除路径。
2. 目标必须精确等于 `<Vault 根目录>/.trash`，不能是 Vault 根目录、空路径、环境变量、通配符或计算后落在其他位置的路径。
3. `.trash` 必须是 Vault 根目录的直属真实目录，不能是符号链接、junction 或其他 reparse point。
4. 先枚举目录的全部直属和递归内容，记录文件数、目录数和总大小。枚举结果只用于报告，不用于筛选来源。
5. 任一安全检查无法确定时停止，不执行部分删除。

## 永久清空

- 永久删除 `.trash/` 下枚举到的全部文件和子目录，无论它们来自哪个流程。
- 不使用未解析变量、宽泛路径、父目录递归删除或可能扩张范围的通配符。
- 保留 `.trash/` 目录本身。
- 如果目录本来就是空的，直接报告已经为空，不制造错误。

## 删除后验证

重新检查 `.trash/`：

- 目录仍然存在；
- 目录内没有剩余内容；
- 没有影响 Vault 的其他路径。

最后报告永久删除的文件数、目录数和总大小，并明确说明内容不可恢复。若有任何项目删除失败，列出精确路径和错误，不把操作描述为成功。
