# Review

复习的目标是重新提取和迁移知识，不是重新阅读笔记或回答低信息量常识题。

## 选择内容

读取 `.learning/mastery-state.json`、`.learning/review-queue.json`、`.learning/learner-profile.json`、活跃 Learning Quest 和近期 Session Log。优先选择：

- 曾经答错或存在误解的概念。
- 很久没有成功提取的概念。
- 与当前问题或项目相关的旧概念。
- 尚未在实际产出中使用的概念。

每次只选择少量高价值内容，并解释为什么现在值得复习。不要重复测试用户刚刚在当前对话中已经展示的能力。

由 `learning-hub review <Quest ID>` 路由而来时，先读取该 Quest 的标题、完成标准、能力证据和历史缺口，只从其中已有掌握证据的内容选择复习任务。Quest 的下一教学节点不属于复习范围。

## 复习顺序

1. 在打开原笔记前要求自由回忆关键机制；若当前对话已有充分解释，直接计入证据。
2. 调用 `assess` 生成一个变化后的真实案例、诊断、预测、设计或权衡任务。
3. 根据回答指出已证明的能力和具体缺口，必要时回到 `teach`。
4. 记录证据等级、错误类型和下次建议时间。

不得绕过 `assess` 的问题准入门槛和语气规则。不要只生成选择题，不要把“看答案后觉得熟悉”记录为掌握，也不要用连续反问拖延。未经用户确认，不修改正式知识笔记。

复习结束后更新掌握状态和 `review-queue.json`，再把证据摘要和本次动作结果交回 `learning-hub`。`.learning/learning-progress.json` 由 `learning-hub` 统一写入，本 Skill 不自行重建该文件。
