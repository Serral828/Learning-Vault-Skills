# Review

复习的目标是重新提取和应用知识，不是重新阅读笔记。

## 选择内容

读取 `.learning/mastery-state.json`、`.learning/review-queue.json`、活跃 Learning Quest 和近期 Session Log。优先选择：

- 曾经答错或存在误解的概念。
- 很久没有成功提取的概念。
- 与当前问题或项目相关的旧概念。
- 尚未在实际产出中使用的概念。

每次只选择少量高价值内容，并解释为什么现在值得复习。

## 复习顺序

1. 在打开原笔记前要求自由回忆或解释。
2. 给一个变化后的例子、判断题、推导或应用任务。
3. 根据回答指出遗漏和误解，必要时回到 `teach`。
4. 记录成功程度、证据、错误类型和下次建议时间。

不要只生成选择题，不要把“看答案后觉得熟悉”记录为掌握。未经用户确认，不修改正式知识笔记。
