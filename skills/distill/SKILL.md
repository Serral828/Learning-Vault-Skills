# Distill

## 晋升门槛

正式 Concept Note 必须同时满足：

- 用户已经用自己的语言解释核心机制。
- 至少完成一次新情境中的判断、推导或应用。
- 关键事实有来源或被明确标注为个人推断。
- 笔记边界足够小，并有一个唯一核心命题。

如果不满足，保留在 `90-学习会话/`，不要伪装成已掌握知识。

## 提炼流程

1. 搜索 `02-概念/`，避免创建重复或近义笔记。
2. 选择清晰的名词短语标题；Topic Map 才使用宽泛主题名。
3. 保留用户原有表达，修正事实错误但不要用 AI 文风覆盖用户声音。
4. 根据 `_templates/概念笔记模板.md` 生成草稿。
5. 提议前置、解释、应用、对比和因果关系，但不得制造无依据链接。
6. 展示完整目标路径和草稿，等待用户明确确认。
7. 确认后才写入 `02-概念/`，再更新掌握状态和相关 Topic Map。

不得直接覆盖已有 Concept Note。需要修改时先展示差异和理由。
